# Game rules

Setup validates 3–20 distinct names, and 1 through floor((players−1)/2) imposters. Setup → role assignment → private reveals → discussion → voting → optional guess → results → new round. Each private reveal must be explicitly hidden before the next player. Switching tabs or losing window focus hides the card.

Discussion ends manually or at its deadline. Voting has 120 seconds; missing votes abstain. No self votes. Votes cannot be edited. Abstention is target −1. With one imposter, a unique highest vote catches that suspect. A top tie catches nobody. With N imposters, the top N vote-getters are caught only if the Nth vote count is positive and strictly greater than the next count. This is disclosed in the rules; each person still casts one vote.

Any caught imposter can guess once if enabled, with 60 seconds for the phase. Canonical, Roman, Devanagari, English and aliases are accepted after normalization. One correct guess wins for all imposters. Blank/skipped or timed-out guesses fail. Otherwise citizens win only if all imposters are caught.

Citizens: +100 for a citizen win, +25 per correct individual vote. Imposters: +150 for survival, or +200 for a correct final guess (not cumulative). Chaos adds +25 to each winning imposter, shuffles speaking order and adds one harmless prompt or shortens discussion by 30 seconds. Undercover uses the related word instead of a blank card and disables final guesses. Local scores retain mode information in the history; the settings scoreboard filters scores by mode. The four base scoring awards can be configured under More settings (0–1,000 each); the Chaos bluffing bonus stays +25.

Independent secure shuffles make roles fair per round; long streaks remain possible. No covert pity rotation or forced role balancing. Ties, abstentions, timeout outcomes and role counts are tested. Incomplete rounds do not save local scores.
