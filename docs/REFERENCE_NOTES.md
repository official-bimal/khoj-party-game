# Reference mechanics

Public reference inspected: [imposter.app](https://imposter.app/).

The reference exposes pass-phone setup with player/imposter counts, hints, categories, custom words and a timer. Its public instructions describe deliberate card reveal, short clues, discussion and identifying the imposter; it links to private online rooms. These mechanics informed the round flow only.

KHOJ uses original branding, a code-drawn detective mascot, original dark/coral/lavender design, Nepali-first draft vocabulary and Roman/Nepali core controls. No reference code or artwork was copied. KHOJ specifies deterministic vote cutoffs, timeouts, final guesses and scoring in GAME_RULES.md and validates them independently.
